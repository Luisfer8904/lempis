# Ideas de nombre para el SaaS

> Propuestas para decidir más tarde. Reemplazar `APP_NAME` en `.env`.

## Generales (cualquier rubro)

| Nombre        | Pros                                               | Contras                          |
|---------------|----------------------------------------------------|----------------------------------|
| **FacturaPro**    | Claro, descriptivo, fácil de recordar             | Algo genérico                    |
| **Factuly**       | Estilo SaaS moderno (-ly), corto, internacional   | No comunica el rubro             |
| **Facturix**      | Tecnológico, único, dominio fácil                  | Suena a empresa farmacéutica     |
| **Factura365**    | Comunica disponibilidad 24/7                       | Imita a Office365                |
| **Facturalia**    | Suena español/LatAm, agradable                     | Algo largo                       |
| **Bilo**          | Corto, moderno, abreviación de "billing"           | Poco descriptivo                 |
| **Facturando**    | Verbo activo, comunica acción                      | Podría confundirse con un blog   |
| **MiFactura**     | Cercano, posesivo, fácil                           | Muy genérico, dominio difícil    |

## Verticales agro (si quieres mantener la línea Invagro)

| Nombre        | Pros                                               |
|---------------|----------------------------------------------------|
| **AgroFactura**   | Claro, comunica el nicho                          |
| **AgroFacil**     | Suena cercano, "facilita el agro"                 |
| **CampoFactura**  | Descriptivo, identitario LatAm                    |
| **AgroBilling**   | Mezcla español + inglés (estilo SaaS)             |
| **FincaPro**      | Apunta a fincas y agro-empresas                   |

## Mi recomendación

**FacturaPro** o **Factuly** si vas por enfoque general (más mercado).
**AgroFacil** si decides quedarte en el nicho agro (menos competencia, ticket más alto).

## Cosas a verificar antes de decidir

1. Disponibilidad del dominio `.com` y `.hn`.
2. Disponibilidad en redes sociales (X, Instagram, TikTok).
3. Que no esté registrado como marca en Honduras / LatAm.
4. Que el nombre se pronuncie igual en español e inglés (si vas internacional).
