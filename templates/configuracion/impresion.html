Impresora de recibos

Esta configuración aplica para tickets de mostrador, recibos rápidos y documentos que salen en impresora térmica.

Impresora de documentos

Esta configuración aplica para facturas detalladas, copias de carta y documentos que salen en impresora normal.

Cómo queda la operación

  • Venta rápida: normalmente usa recibo térmico.
  • Venta detallada: normalmente usa carta.
  • Recibos de cobro: pueden salir en térmica o carta según tu flujo.
  • Orden de carga: si se habilita, aparece como documento imprimible dentro de cada factura.
  • El cajón solo se intenta abrir si está activa la opción de arriba y el navegador tiene permiso para usar la impresora o puerto serial.
